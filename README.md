# Transportation-Accessibility

単日開催セミナーにおける、視覚障害のある参加者への交通アクセシビリティ対応について、複数の生成AI（Copilot・ChatGPT・Claude・Gemini）に検討してもらった内容を、比較・整理して共有するための資料です。

## 公開ページ

| バージョン | URL | 内容 |
|---|---|---|
| 簡易版 | https://calico-blanket.github.io/Transportation-Accessibility/ | 4者の提案を項目ごとに簡潔に並べたバージョン |
| 詳細版 | https://calico-blanket.github.io/Transportation-Accessibility/detail/ | 各項目について、具体例や「なぜその提案になったか」という背景まで補足したバージョン |

## 経緯

1. Copilot・ChatGPT・Claude・Geminiの4者に、それぞれ「単日開催セミナーで、視覚障害のある参加者を迎える際の交通アクセシビリティ対応」を検討してもらった（Claudeとの会話は本リポジトリとは別に、チャット形式でも整理済み）。
2. 4者の回答をWord文書として集め、重複する主張と、資料ごとに異なる視点を項目別に比較整理した。
3. 比較表形式は情報が詰まって見にくかったため、オンラインで複数人に共有・説明しやすいよう、HTML資料として再構成した（アクセシビリティ配慮：コントラスト比の確認、キーボード操作可能な開閉パネル、レスポンシブ対応など）。
4. 各項目の内容が簡潔すぎたため、具体例と提案の背景（なぜその対応が推奨されるのか）を補足した詳細版を追加作成した。
5. 簡易版・詳細版をどちらも参照できるよう、詳細版を `detail/` フォルダに配置し、GitHub Pagesで両方を同時公開した。

## 構成

```
/
├─ index.html         … 簡易版（公開ルート）
└─ detail/
   └─ index.html      … 詳細版
```

## 使い方

- セミナーや発表の場で画面共有する際は、まず簡易版で全体像を示し、深掘りしたい項目があれば詳細版の該当箇所を開く、という使い方を想定しています。
- ページ内の各テーマは開閉パネル（タップ/クリックで開閉）になっているため、話したいテーマだけを開いて説明できます。

## 更新について

内容を修正する場合は、該当する `index.html`（ルートまたは `detail/` 配下）をGitHub上で直接編集し、コミットしてください。反映まで数分かかることがあります。
